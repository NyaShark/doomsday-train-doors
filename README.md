# 末日车门

《末日车门》是一款单屏、30 秒一局的 2D 反应分轨网页游戏。玩家读取幸存者携带的颜色与形状标记，在三条避难门中选择对应轨道。门牌映射会在连击和阶段变化时重新排列，因此每完成一段连击都需要重新读取画面。

## 直接游玩

- 在线版：https://nyashark.github.io/doomsday-train-doors/
- 本地版：双击根目录的 `index.html`，不需要安装依赖或启动服务器。

建议使用当前版本的 Chrome、Edge 或 Safari。页面不依赖登录、联网接口、外部字体、CDN 或后端服务。

## 操作

| 操作 | 设备 | 行为 |
| --- | --- | --- |
| 点击或轻触避难门 | 手机、电脑 | 选择对应轨道 |
| `1` / `2` / `3` | 电脑 | 选择左、中、右轨道 |
| `Space` | 电脑 | 暂停或继续 |
| `R` | 电脑 | 结算后重新开始 |

## 规则

- 单局时长为 30 秒。
- 送对 20 名幸存者即撤离成功。
- 送错或漏送会损失 1 次生命；共 3 次生命。
- 连续送对会增加分数倍率，倍率最高为 2 倍。
- 连击达到 5、阶段进入变化期或达到指定正确数时，避难门映射会先警示 0.4 秒，然后重新排列。
- 第三阶段会插入 1 次 0.15 秒的假色信号抖动，假信号不改变实际门牌映射。
- 每名幸存者必须在到站前完成一次轨道选择。

## 验收要点

- 根目录存在 `index.html`，本地双击可以直接进入标题页。
- 不登录、不连接后端也能开始、操作并完成一局。
- 手机与桌面均可见三条轨道、当前目标、生命、分数、倒计时和连击。
- 胜负条件、映射变化和输入边界均可在实际游玩中验证。
- 根目录 PDF 与提示词备份齐全，过程可追溯。

## 技术说明

- 无构建步骤，原生 HTML、CSS 与 JavaScript。
- 音效由 Web Audio 实时合成，不依赖外部音频文件。
- `window.__DOOM_GAME__` 仅用于自动化验收，不参与正常操作流程。
- 游戏状态保存在当前页面内存，不使用 Cookie、本地存储、账号或服务器。
